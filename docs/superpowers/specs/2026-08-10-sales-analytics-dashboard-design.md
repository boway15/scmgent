# 销售分析看板设计

> **状态**：待实现  
> **日期**：2026-08-10  
> **目标**：在 scm-agent 增加独立「销售分析看板」，基于库内销售历史预聚合 Cube，提供月/周多维复盘与看板内轻量外推（不进发布版预测）。

---

## 1. 背景与决策

业务侧已有 Workbuddy 离线原型「产品销售多维分析看板」（宽表 Excel/CSV → `analysis_data.json` → 单页 HTML）。期望在自建栈中提供同类经营看板，与现有「销量预测」版本作业流并列，而非替换。

| 决策项 | 结论 |
|--------|------|
| 产品定位 | **A**：经营复盘看板（历史多维分析为主） |
| 数据来源 | **A**：仅库内 `sales_history` / `sales_history_monthly`，不做 Excel/CSV 导入重算 |
| 轻量外推 | **B**：保留（趋势/季节/均线/朴素），仅看板展示，不进发布版 |
| 时间粒度 | **B**：一期同时支持月度 + 周度 |
| 入口 | **B**：独立菜单项（非预测子 Tab） |
| 组别口径 | **B**：看板专用从品类路径解析，保留「海外项目X组」；不用 `skus.project_group` |
| 实现架构 | **方案 1**：预聚合 Cube + 一次拉取 + 前端交互筛选 |
| Cube 存储 | 最新成功快照表（`payload` jsonb） |

**刻意不做（一期）**

- Excel/CSV 导入生成看板
- 与系统发布版预测同屏对比
- 原型「项目组四大类」`g`（亚马逊/非亚马逊/品牌独立站/营销部）作为主筛维
- 固定 cron（可后续加）；一期以手动刷新 + 可选导入后触发为主
- 整页导出（矩阵 CSV 一期做；整页导出二期）

---

## 2. 架构

```
sales_history (日)
       │
       ▼ 刷新任务（手动 / 导入后可选触发）
sales_analytics_cube_snapshots（最新 ready 快照）
       │
       ▼ GET /api/sales-analytics/cube
React 看板页（KPI / 图 / 矩阵 / 轻量外推，浏览器内计算）
```

1. Cube 实体：一行 = 站点 × 组别 × 品类 × 平台；含月向量 `v[]`、周向量 `vw[]`，以及 meta（期列表、各维枚举、`generated_at`）。
2. 月序列优先从 `sales_history_monthly` 卷起；周序列从 `sales_history` 按 ISO 周聚合后写入同一快照。
3. 筛选、KPI、图表、矩阵、轻量预测均在前端基于 cube 计算；改筛选不打聚合 SQL。
4. 轻量预测结果不写库、不进 `sales_forecast_*`、不参与补货。
5. 路由：`/data/sales-analytics`；菜单文案：「销售分析看板」。

## 3. 维度与口径

### 3.1 Cube 主键四维

| 维 | 字段 | 来源与规则 |
|----|------|------------|
| 站点 | `s` | 优先 `sales_history.station`（日销报表「站点」归桶 **US / EU / UK / 其他**；德国等→EU）；空则品类路径 token → `warehouse_code` 映射；仍未知 → **其他**。UK 单独成桶，不并入 EU。 |
| 组别 | `b` | 品类路径（优先行上 `category` 快照，空则回退 SKU `category`；分隔符 `\`/`/` 先规范化）正则取「项目X组 / 海外项目X组」；路径含「海外」→ `海外项目N组`，否则 `项目N组`；无匹配 → 路径首段或 `(未分组)`。**不使用** `skus.project_group`。 |
| 品类 | `c` | 规范化后路径最后一段（叶子）；空 → `(未分类)` |
| 平台 | `p` | `channel` 经现有平台别名归一到平台 code；看板展示用中文名（无则 code）；空/未知 → `(未标注平台)` 或 UNKNOWN 展示名 |

### 3.2 度量与时间

- 度量：销量件数（`qty_sold` 求和）。不做金额。
- 月标签：`YYYY-MM`，与月汇总 year+month 对齐，升序。
- 周标签：ISO `YYYY-Www`，由日表 `sale_date` 聚合，升序。
- 期段筛选：起止 inclusive；KPI「最新期」= **当前筛选止期**。

### 3.3 环比 / 同比

- MoM：本期 vs 上一期（随粒度：上月 / 上周）。
- YoY：本期 vs 去年同标签（`2026-07`↔`2025-07`；`2026-W12`↔`2025-W12`）；对不上则为空。

### 3.4 与预测模块边界

- 本看板的站点归桶、组别解析仅服务分析页；**不修改**预测生成中的 station / `project_group` 语义。
- UI 须标注粗估「非系统发布预测」。

## 4. 数据模型

表：`sales_analytics_cube_snapshots`

| 列 | 类型 | 说明 |
|----|------|------|
| `id` | uuid PK | |
| `status` | varchar | `running` \| `ready` \| `failed` |
| `generated_at` | timestamptz | 成功完成时间（ready 时有值） |
| `meta` | jsonb | 摘要：期段、实体数、各维枚举摘要、源统计等 |
| `payload` | jsonb | 完整 cube：`{ meta, months, weeks, data[] }`；`data` 项为 `{ s,b,c,p,v,vw }` |
| `error_message` | text | failed 时原因 |
| `created_at` | timestamptz | 任务创建时间 |
| `created_by` | uuid 可空 | 触发人 |

- GET 读最新 `status = ready` 一行。
- 一期 payload 以 jsonb 存全文；实体量约千级可接受。若后续过大再拆对象存储/压缩。
- 重建中写入 `running` 行（或更新进行中任务）；成功后新 `ready` 生效；失败保留上一份 `ready` 供阅读。
- 清理：重建成功后可只保留最近若干条快照（建议 ≥3，含最新 ready），避免表膨胀。

## 5. API

| 方法 | 路径 | 作用 |
|------|------|------|
| `GET` | `/api/sales-analytics/cube` | 返回最新 ready 的完整 `payload`；无快照 → 404/约定空态码 |
| `POST` | `/api/sales-analytics/rebuild` | 触发重建；并发中返回 409 或等价 |
| `GET` | `/api/sales-analytics/status` | `generated_at`、行数、期段、是否 `running`、最近错误 |

权限：读 cube/status 与销售历史同级；rebuild 需写/运营权限（对齐现有菜单权限模型）。

## 6. 页面

路径：`/data/sales-analytics`

模块（对齐 Workbuddy 原型）：

1. 顶栏：标题、`generated_at` / 数据区间、【刷新数据】
2. 月度 / 周度 Tab
3. KPI：最新期销量、MoM、YoY、区间累计、命中实体数
4. 筛选：主维度（站点/组别/品类/平台，可多选组合）+ 四维多选 + 期段起止
5. 图表：期销量柱图；MoM/YoY 折线
6. 明细矩阵：组别 / 站点 / 交叉组合；历史期列 + 预测期列（高亮）+ 模型名 + 累计/环比/同比/峰谷；点击行锁定走势图
7. 底部预估：筛选内 / 全量；月 horizon 5–12（默认 12，对齐 demo）；周 20–52（默认 20）；图 + 表 + 依据说明
8. 导出：一期支持矩阵 CSV

空态：无快照引导刷新；重建中禁用二次刷新并显示进度；筛选无命中显示空态不报错。

## 7. 轻量预测

- 自动选型：线性趋势 / 趋势+季节 / 移动平均 / 朴素法（阈值与原型同量级：R²、趋势相对强度、季节强度）。
- 月度可叠加月季节因子（乘法）；周度不做月季节，退化为趋势 / 均线 / 朴素。
- 应用位置：矩阵行级外推 + 底部合计（筛选内 / 全量）。
- **硬边界**：不落库、不进发布版、不进补货与准确率；界面明确「看板粗估」。
- **粗估口径**：矩阵预测列与底部预估统一为「月：趋势×季节；周：线性趋势」；不以移动平均/朴素法作为默认外推；可用 R² 标注可信度。

---

## 8. 刷新策略

- 触发：页面【刷新数据】；销售历史导入成功后**可选**异步触发（不阻塞导入）。
- 一期不做固定 cron。
- 并发：全局仅一个 rebuild；进行中拒绝新任务。
- 失败：保留上一 ready 快照；status 记录错误。
- 新鲜度：顶栏展示 `generated_at`；若历史已更新而快照未重建，可提示用户刷新。

## 9. 测试与验收

### 9.1 测试

- 维度解析单测：组别（含海外）、站点归桶、品类叶子、平台归一
- 聚合：多仓/多渠道卷到四维键不双计、不漏计
- MoM/YoY：首期、缺同比期
- 模型选择：短序列 / 强季节 / 无趋势
- API：无快照、重建中、重建成功切换
- 前端 smoke：筛选组合、锁行、月/周切换

### 9.2 验收

- 独立菜单可进入看板
- 月/周可切换；四维筛选与矩阵下钻可用
- 数据来自库内历史经 cube，非 Excel
- 粗估可见且标明非发布预测
- 刷新后 `generated_at` 更新且图表合理变化
