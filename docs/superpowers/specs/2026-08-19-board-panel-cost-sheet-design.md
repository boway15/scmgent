# 产品成本核算：按每块板规格展开板材成本表

**日期**：2026-08-19  
**状态**：已评审  
**基线**：`docs/superpowers/specs/2026-08-19-costing-facts-confirm-calc-design.md`  
**对照**：业务 Excel「板材成本核算（按照每个板材的规格进行核算）」  
**拍板**：路径 1（计算层宽表，不改识别流程）+ 范围 C（开料/封边/打孔/开槽/喷漆五列；无规则的默认为 0，可本单手填）。同期纳入：取消「其他五金占比」、默认螺丝包、包装进成本。

## 1. 背景

业务按**一块板一行**核算：张价 ÷ 开料片数得到板材成本，再在同一行加开料、封边、打孔、开槽、喷漆。现网板材按面积 ×（1+损耗）折张价，加工是价目里的独立「加工」行，对不齐这张表。

本迭代改**计价、第二步配件/包装物料、第三步展示与导出**。不改第一步结构识别、不改类目开料公式、不改 Dify 拆 BOM。

## 2. 用户故事

- 作为采购员，我希望第三步看到与业务表同结构的板材明细（厚、长、宽、元/张、开料片数、五列工艺、行小计），以便对账。
- 作为采购员，我希望打孔/开槽/喷漆没有规则时先为 0，本单能手填，且不写回价目。
- 作为采购员，我希望板上已含开料/封边后，清单里的独立加工行不再加进总额，避免算两次。
- 作为采购员，我希望不再用「其他五金占比」加成；每件产品默认 1 包螺丝包（10 元），包装（护角/保利龙/纸箱）按成品外形进材料成本。

## 3. 板材成本（已确认）

大板采购标称 **1220 × 2440 mm**（张价折 m² 仍用此面积）。开料片数按修边后净料 **1200 × 2400 mm**，固定方向、不旋转。仅 `category === '板材'` 且能从 spec 拆出长、宽的行走本公式。

开料片数 = `floor(1200 / 宽) × floor(2400 / 长)`

- **长**：零件较长边（mm）；**宽**：较短边。
- 不取另一种摆法的较大值（与业务 Excel 一致）。
- 行上快照字段：`usableWidthMm=1200`、`usableLengthMm=2400`。

板材成本 = `(元/张 ÷ 开料片数) × 数量`

- **元/张**：该行生效单价（价目匹配的张价，或本单 `unit_price_override`）。匹配逻辑仍按厚度 + 基材（`defaultSubstrate` 映射结构件名）。
- **数量**：`qty_net`（件数）。
- **不乘**现网 8% 损耗。片数已是整数套料。
- 开料片数 &lt; 1（零件大于净料 1200×2400 或缺尺寸）：**退回**现网面积计价（含损耗），该行明细标注「按面积」。
- 缺张价：仍算缺价，计算闸门与现网一致。

## 4. 五列工艺（已确认）

周长米（默认）= `2 × (长 + 宽) / 1000 × 数量`。长宽单位 mm。

| 列 | 默认用量 | 默认单价 | 金额 |
|----|----------|----------|------|
| 开料 | 周长米 | 价目「加工 / 开料」元/m，缺省 0.3 | 用量 × 单价 |
| 封边 | 周长米（默认四周） | 价目「加工 / 封边」元/m，缺省 0.5 | 用量 × 单价 |
| 打孔 | **0** | 价目「加工 / 打孔」元/个，缺省 0.15 | 个数 × 单价 |
| 开槽 | **0** | 缺省 0.5 元/m（价目有「开槽」则用价目） | 米 × 单价 |
| 喷漆 | **0** | 价目有「喷漆」则用其元/m²，否则 0 | 面积 × 单价 |

价目切片与区域/工厂一致。手填只存本单该板材行，不写回 `material_price_book`。

覆盖字段（JSON，未出现的键表示用默认）：

- `cutMeters` / `bandMeters` / `drillCount` / `grooveMeters` / `paintAreaM2`
- 可选覆盖单价：`cutRate` / `bandRate` / `drillRate` / `grooveRate` / `paintRate`

改覆盖后清除成本快照（与改用量相同），须重新点「计算成本」。

行小计 = 板材成本 + 五列金额。

## 5. 螺丝包、五金与包装（已确认）

这些行**不进入**「板材成本明细」宽表，进入**材料小计**（与板材成本、五金滑轨等并列）。

### 5.1 取消其他五金占比

- 页面去掉「其他五金占比」输入；`calcCostSummary` **不再**按材料小计加成「其他五金」。
- 列 `other_hardware_pct` 可保留但计算忽略。
- 清单里零散「拉手 / 螺丝（非螺丝包）/ 螺钉 / 三合一」仍视为已覆盖、**不计行价、不拦计算**，避免与螺丝包重复。

### 5.2 螺丝包

- 所有产品默认 **1 包**，名称「螺丝包」，单位「包」，大类「五金」。
- 通用价 **10 元/包**（价目全局行；无匹配时本单按 10 元计）。
- 在第二步「配件」区固定展示，并在重算结构件时写入 BOM。
- 「螺丝包」**不是** bundled 其他五金，必须计价、缺价则拦计算。

### 5.3 包装

有整柜外形 W×D×H 时，重算结构件 upsert（无外形则不造包装行）：

| 名称 | 大类 | 数量 | 规格 |
|------|------|------|------|
| 纸护角 | 包装 | 4 个 | 外径 = 成品各边 + **80 mm**；成本 = 4 × 0.5 |
| 保利龙 | 包装 | 六面展开面积 × 20mm → m³（四位小数） | 同上外径；成本 = 体积 × **280 元/m³** |
| 纸箱 | 包装 | 六面展开面积 m²（四位小数） | 同上外径、200磅；成本 = 面积 × **4.9 元/m²** |

不生成隔板 / 保利龙2 / 纸箱2 空行。保利龙按体积计价，不按 kg。

纸护角价目抽样 0.5 元/个。清单分组顺序：板材 → 五金 → 包装 → 其它。

第三步看板旁增加只读「配件与包装」：螺丝包、滑轨等计入的五金行、三行包装的数量/单价/金额，便于和板材宽表分开对账。导出增加 sheet「配件与包装」，或放在汇总 sheet 的材料分类下必须能看出包装金额。

## 6. 总额与独立加工行

识别独立加工行（**不计入**材料/加工/总成本）：

- `category === '加工'`，且规范化名称属于：开料、封边、打孔、开槽、喷漆。

PVC 封边条等**材料行**（非「加工」大类）仍计入材料。螺丝包与包装按第 5 节计入材料小计。

看板：

| 项 | 构成 |
|----|------|
| 材料小计 | 板材行的**板材成本** + 计入的五金（含螺丝包、滑轨等）+ 包装 − bundled 拉手/散装螺丝 |
| 加工费 | 全部板材行五列工艺之和（不再加独立加工行） |
| 费用系数 | 现网工厂费率，基数 = 材料小计 + 加工费 |
| 总成本 | 材料 + 加工 + 费用 |

第二步 BOM 板材行展示金额 = **行小计**（与明细表一致）。独立加工行可仍显示在清单中，匹配状态照旧，但计算时金额视为 0，且不因缺价/缺用量拦截计算。

## 7. 页面与导出

- 第二步：配件区展示螺丝包（1 包 / 10 元）及缺件滑轨/防倾倒；清单分组板材 → 五金 → 包装。板材行可增加只读「开料片数」提示；工艺手填放在第三步。
- 第三步看板旁只读「配件与包装」：螺丝包、计入的五金、三行包装。其上方为「板材成本明细」宽表：序号、板子、材质、厚度、元/张、数量、长度、宽度、开料净宽、开料净长、开料片数、板材成本、开料（米/单价/金额）、封边、打孔、开槽、喷漆、行小计。合计行对齐业务表。
- 材质列：结构件显示项目 `defaultSubstrate`，否则显示材料名。
- 导出 Excel 增加 sheet「板材成本核算」，列与宽表一致；增加「配件与包装」或在汇总中单列包装/螺丝包金额。原「清单 / 汇总」保留。汇总中加工费按第 6 节口径。未点计算则明细可出数量尺寸，金额列空并提示先计算。

## 8. 数据与 API

- `costing_bom_lines` 增加 `process_overrides` jsonb，默认 `{}`。
- `PATCH` 板材行允许更新 `process_overrides`；改后 `cost_computed_at` / `cost_summary` 置空。
- `GET` 项目详情：每条板材行带计算后的明细快照字段（计算前也可返回实时预览用量，金额以是否已计算为准，与现网看板「未计算显示 —」一致）。
- 成本快照 `cost_summary` 增加 `boardSheet`：各板材行明细数组 + 列合计，便于刷新页面不丢宽表。

螺丝包/包装行无额外 JSON；沿用 BOM 字段与价目匹配。`apply-facts` / 识别完成后有外形即开料并写入包装（纸护角/保利龙六面×20mm/纸箱展开 m²）。模型拆出的保利龙整箱体积行会被覆盖。点「重算结构件」仍须五项板厚齐全，以便用确认厚度覆盖默认值。

## 9. 非范围

- 更复杂套料（余料条、多规格混排）、锯缝、封边只封指定边的类目规则。
- 按结构件类型自动猜孔数/开槽/喷漆。
- 改 Dify Prompt、改箱体开料公式、手填单价写回价目。
- 第一期不把工艺列做到第二步 BOM 主表。
- 包装余量不按 SKU 手填；固定 +80 mm。不按 9 抽柜的包装尺寸套当前产品。
- 不恢复「其他五金占比」加成。

## 10. 验收

1. 有长宽的板材：开料片数 = floor(1200/宽)×floor(2400/长)；板材金额 = 张价÷片数×件数；与面积×(1+8%) 及「两种摆法取优」结果允许不同。
2. 未选手填时：开料米=封边米=周长米；打孔/开槽/喷漆金额为 0。
3. 本单改打孔个数后，行小计含打孔费；价目无新行。
4. 清单存在「加工 / 开料」独立行时，总成本不含该行，只含板上开料列。
5. 点计算后宽表与看板材料/加工拆分相符；再改覆盖须重新计算。
6. 导出含「板材成本核算」sheet，列齐全。
7. 无「其他五金」费用项；总成本含 1 包螺丝包（10 元，价目或本单）。
8. 有外形时清单含纸护角 4、保利龙（六面×20mm 体积）、纸箱（展开 m²）；材料小计含其金额。散装「螺丝」不计价。
