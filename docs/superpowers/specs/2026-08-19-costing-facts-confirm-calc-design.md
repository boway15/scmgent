# 产品成本核算：先抽结构事实、确认原材料、最后算成本

**日期**：2026-08-19  
**状态**：已评审  
**基线**：`docs/superpowers/specs/2026-08-13-product-costing-tool-design.md`（本 spec 修订其中「不做确认闸门 / 看板现算」）  
**范围**：核算页短表补全、类目结构规则（斗柜/床头柜公式锁定）、原材料确认、本单补价、计算闸门。  
**不改**：手填价写回共用价目、强制结构部改 PPT。拆 BOM 工作流仍只出物料行；第一步结构判断用独立 facts 工作流。

## 1. 背景

打样 PPT 常缺 CMF / 五金表，模型拆料不准。现网拆完即现算看板，缺价只标红，业务会把不完整金额当成正式成本。

拍板：

- 缺内容在**核算页短表**补，不改 PPT 重传。
- 手填单价**只应用本单**，不写入成本库（价目）。
- 先解析产品核心元素，再按**类目结构规则**展开板件。
- 斗柜 / 床头柜抽侧宽采用 **A：抽面高 − 60mm**（与现网 `carcass-cut-rules` 一致）。
- **先确认原材料**（库中无此材料则手填本单单价），**最后**点计算才出成本。

## 2. 用户故事

- 作为采购员，我希望先看到品类、基材、抽屉数等核心元素，并按斗柜/床头柜规则得到结构件开料，以便核对料而不是核对模型胡猜。
- 作为采购员，我希望 PPT 缺材质/板厚/五金时，在核算页填一张短表即可应用，不必让结构改稿。
- 作为采购员，我希望成本库没有的材料只在本单填价，确认齐套后再算总成本，以免把缺价草稿当成报价。

## 3. 页面流程（同一核算页，三步向导）

```
列表点「新建」（不填表）→ 详情先上传 PPT/PDF → **大模型判断品类/结构/拆料原则**（结果可改）
  → ① 确认产品信息与设计标准（无物料清单）
  → ② 按已确认标准 + 爆炸图/尺寸图识别物料
  → ③ 价格计算与确认
```

| 步骤 | 可见 | 主按钮 |
|------|------|--------|
| ① 结构及设计识别与确认 | 上传；模型回填名称/品类/抽屉/基材/板厚/结构说明/拆料原则，**均可修改** | 「确认设计标准，识别物料」 |
| ② 物料确认 | 爆炸图+尺寸图拆出的材料清单 | 「确认物料，进入计价」 |
| ③ 计价 | 区域/工厂 + 成本看板 | 「计算成本」 |

区域 / 工厂选择仍只影响价目切片，不改变结构展开。

## 4. 核心元素短表

顶栏已有：品类、结构类型、抽屉数、基材。本迭代补到同一「结构补全」卡片：

| 字段 | 说明 |
|------|------|
| 品类 | 斗柜 / 床头柜 / 书桌 / 梳妆台 / 其他 |
| 结构 | 板式 / 实木 / 混合（可选） |
| 抽屉数 | 0–30 |
| 基材 | 颗粒板 / 密度板 / 多层实木板 / 实木 / 其他 |
| 箱体板厚 mm | 可选；属于设计标准，有则覆盖从 PPT 推断的箱体厚度 |
| 抽底板厚 mm | 可选；属于设计标准，默认推断 9mm |
| 五金 | **不在第一步**。滑轨/拉手/防倾倒在第二步按文档识别；仅文档缺失时允许本单补全，空行不造料 |

规则：

- 短表 **优先于** PPT / 模型对上述字段的猜测。
- 「应用补全」：不重跑 AI；按类目规则重算结构件开料、重匹配价目、按短表 upsert 五金（`notes` 含「人工补全」，本单覆盖）。
- 再跑 AI 结束后自动再应用一遍短表，避免冲掉人工五金与板厚。
- 未填板厚 / 基材：仍出草稿清单；**未填的五金绝不臆造**。
- 第一期不做：封边厚度、侧板落地开关（斗柜/床头柜代码默认落地，见 §5）。

## 5. 类目结构规则（代码，不进 LLM Prompt 长文）

解析与「应用补全」都走服务端 `category-rules` + `carcass-cut-rules`。LLM 继续拆明示物料；结构件开料以规则为准。

### 5.1 斗柜 / 床头柜（默认，不可被模型改掉）

1. **顶板为盖板**：顶板长 = 柜宽，宽 = 柜深；盖住侧板。
2. **侧板落地**：无整块底板；柜内宽处两根 50mm 落地拉条。
3. **前拉条数量**：爆炸图/物料清单 **明示件数优先**；无明示时 fallback `ceil((n-2)/2)`；1–2 抽为 0；3–4→1；5–6→2；7–8→3。
4. **抽盒**（抽面尺寸来自尺寸图明示，否则按抽屉网格推断单格抽面）：
   - 抽侧长 = 柜深 − 50mm
   - 抽侧宽 = **抽面高 − 60mm**（方案 A）
   - 抽底长 = 抽侧长
   - 抽底宽 = 抽面宽 − 45mm
   - 抽侧数量 = 抽屉数 × 2

柜宽 > 柜深时背板对开，并加一根背拉条（沿用现网）。

### 5.2 书桌 / 梳妆台 / 其他

不套用侧板落地与前拉条公式。仍用各自必有槽位（书桌：桌面、侧板、横撑、抽面/抽侧/抽底；梳妆台：台面、侧板、抽盒）。外形未解析出则不强行开料。

## 6. 原材料确认与本单补价

取代 2026-08-13「不拦截查看成本」。

- 每行展示价目状态：精确匹配 / 名称匹配 / **未匹配**。
- **未匹配**（成本库无此材料，或同名多规格对不上）：必须填写本单单价（`unit_price_override`）。不写回 `material_price_book`。
- 已匹配行默认用库价，允许改本单覆盖（临时报价），同样不写回价目。
- 业务可改名称、规格、用量、增删行；改后清除「已计算」状态。
- 「加入成本库」本迭代不做。

## 7. 计算闸门

「计算成本」启用条件（同时满足）：

1. 每条计入成本的行都有有效单价（库价或本单覆盖）。
2. 每条计入成本的行 `qty_net > 0`。用量为 0 的模板空行须删掉或补用量，否则禁用计算。

点下后按现有 `cost-calc`（材料 + 加工费 + 费用系数）算出结果，**写入本单成本快照**并展示看板。  
之后改清单、短表、区域/工厂：快照失效，看板提示需重新计算，**不以 GET 现算覆盖快照**（与 2026-08-13 现算策略不同）。

导出 Excel：仅在已计算且快照有效时带成本汇总；未计算则只出材料清单或提示先计算。

## 8. 数据模型

`costing_projects` 增量字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| carcass_thickness_mm | integer null | 箱体板厚 |
| drawer_bottom_thickness_mm | integer null | 抽底板厚 |
| hardware_facts | jsonb null | `[{ name, spec, qty }]` 短表五金，名称限价目标准名：抽屉滑轨、拉手、防倾倒配件 |
| cost_computed_at | timestamptz null | 有值且未失效 = 已计算 |
| cost_summary | jsonb null | 计算快照（与现 `CostingSummary` 同形） |

改 BOM 行、PATCH 短表、改区域工厂时：`cost_computed_at`、`cost_summary` 置空。  
`unit_price_override` 语义不变：仅本单。

不新增项目状态枚举值；仍用 `draft` / `extracting` / `ready` / `extract_failed`。前端用 `cost_computed_at` 区分「确认中 / 已计算」。

## 9. API

- `PATCH /costing/projects/:id`：增加板厚、五金短表字段。
- `POST /costing/projects/:id/apply-facts`：应用短表 + 类目规则（可与 PATCH 合并：保存短表后服务端应用）。推荐独立 endpoint，避免每次改抽屉数都静默改 BOM。
- `POST /costing/projects/:id/compute`：校验齐套后写快照；不齐套 400，body 列出缺价/缺用量行。
- `GET` 详情：返回 `costSummary`（快照或 null）、`costStale`、短表字段；**不再**每次 GET 现算总金额填进看板（行上仍可显示匹配状态与库价，便于确认）。

解析结束后：按**第一步已确认**的品类/抽屉/板厚/结构说明/拆料原则 merge 模板槽位 → `enrichBomFromProductFacts` → 五金 upsert。第二步拆 BOM 不得用 OCR 覆盖已确认字段。

## 10. 非范围

- 手填价自动写入价目
- 结构部 PPT 母版强制校验阻断上传
- 把 LLM 改成只输出事实 JSON（本迭代已用独立「结构识别」工作流；拆 BOM 仍输出 lines）
- 书桌/实木异形专用开料公式
- 确认审批流 / 飞书待办

## 11. 验收

1. 斗柜 6 抽、柜深 400：抽侧长 350；抽侧宽 = 抽面高 − 60；抽底宽 = 抽面宽 − 45；前拉条 2；无整块底板；顶板长 = 柜宽。
2. 短表填基材 + 箱体 18mm + 滑轨数量 = 抽屉数，点应用补全后结构件与五金按规则更新。
3. 未匹配行无本单补价时，「计算成本」禁用或 400。
4. 本单补价后计算成功；共用价目无该材料新行。
5. 计算后再改用量，看板为未计算，需再点计算。
6. 书桌产品不出现斗柜落地拉条默认展开。
