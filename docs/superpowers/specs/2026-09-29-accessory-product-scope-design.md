# 配件商品范围：不含配件 / 只看配件

**版本**：v1.0（2026-09-29）  
**定位**：销量、库存、预测、备货查询默认不含配件 SKU，并可一键切到只看配件。  
**本期做法**：方案 A，查询时过滤，不改表结构。  
**本期不做**：落库 `is_accessory`、配件独立页面、需求计划纳入配件、BOM 五金配件。

---

## 1. 目标

配件是特殊商品，销量、预测、备货默认不把它算进成品口径。用户要能在同一批页面里快速分开看。

成功标准：

- 范围内页面默认只含非配件 SKU；列表、汇总、导出同一口径。
- 同一位置可切到「只看配件」，两种范围互斥，加总覆盖全部 SKU。
- 预测计算出现「不含配件」选项，默认勾选；取消勾选只影响这一次计算。
- 需求计划继续一律不含配件，不能切到只看配件。
- 需求计划、预测计算、预测结果，以及所有默认不含配件的页面，都在操作区旁边写明原因，用户不用猜数字里有没有配件。

## 2. 决策

| 项 | 选择 |
|----|------|
| 做法 | 查询参数 `productScope=goods\|accessory`，缺省 `goods` |
| 判定 | 沿用 `isAccessorySku`：`skuKind=accessory`，或编码解析为配件，或变化段含 `P` |
| SQL | 扩展 `planning-accessory-filter.ts`：`goods` 用现有排除条件，`accessory` 用其否定 |
| 第三档「全部」 | 不做。要对照全量，分别查两次 |
| 退货 / 多箱 | 算非配件，留在 `goods` |
| 持久化 | 选择写入地址栏 `productScope`；不记用户偏好，每次打开默认 `goods` |
| 需求计划 | 生成与列表继续硬排除；不提供范围开关 |
| 预测计算 | 对话框增加「不含配件」，默认勾选，等同今天的硬排除 |
| 预测结果 | 与其它页面一样可切 `goods` / `accessory`。该版本未计算配件时，「只看配件」为空，并说明原因 |
| 单 SKU 直达 | 按 SKU id / 精确编码打开的规划页、抽屉仍显示该 SKU，并标「配件」 |
| 写入与同步 | 飞书入库、销量导入、库存快照不按此参数丢行 |

## 3. 口径

`goods` 与 `accessory` 是补集：

- **不含配件**：成品、多箱、退货，以及其他非配件 SKU
- **只看配件**：`isAccessorySku` 为真的 SKU

`skuKind=accessory` 时，即使编码不像配件，也算配件。编码像配件时，即使 `skuKind` 是成品，也算配件。与当前预测排除规则一致。

成本核算里的「配件与包装 / 防倾倒配件」是 BOM 物料，不是配件 SKU，不走这个开关。

## 4. 范围

### 4.1 读路径（默认 `goods`，可切 `accessory`）

列表、汇总卡片、导出都吃同一个 `productScope`。

| 页面 | 路由 |
|------|------|
| 库存总览 | `/inventory/overview` |
| 库存查询 | `/inventory/query` |
| 库存池 | `/inventory/pools` |
| 未分配供应 | `/inventory/unallocated` |
| 经营看板 | `/inventory/planning-dashboard` |
| 安全库存 | `/inventory/safety` |
| 库存预警 | `/inventory/alerts` |
| 补货建议 | `/pmc/suggestions` |
| 销量历史 | `/data/sales` |
| 销量分析 | `/data/sales-analytics` |
| 销售预测结果 | `/data/forecast/:versionId` |
| SKU 规划入口检索 | `/inventory/planning` |

数据问题队列 `/inventory/data-issues` 同样默认不含配件，并显示「另有 N 条配件问题」。N 按当前其它筛选统计，不含配件范围内的问题仍走原列表。

### 4.2 预测计算

新建或重算销售预测时增加复选框「不含配件」，默认勾选。复选框下方固定一段说明，勾选与取消时都看得见。

- 勾选：配件 SKU 不写入该版本（保持 `forecast-collaboration` 现有跳过行为）。
- 取消勾选：这一版可以写入配件行；结果页用「只看配件」查看。说明改为：本次会把配件 SKU 写入预测，备货仍以需求计划为准，需求计划不含配件。

### 4.3 需求计划

`/data/demand-plan` 与版本明细保持一律不含配件：生成与查询继续 `excludeAccessorySkuSql` / `isAccessorySku`。页面不放范围开关。

列表页和版本明细页都放常驻说明，替换现在只在生成草稿副标题里的一句「配件 SKU（变化含 P）自动跳过」。说明要写清三件事：本页数字一律不含配件、为什么（配件不参与备货）、要看配件去哪一页。

### 4.4 不改

- 商品主数据 `/data/products`：仍显示全部 SKU，行上标「配件」，筛选里可另选配件，默认不隐藏。
- 采购跟单、PMC 已下计划、FOB、成本核算、物流运单。
- 单 SKU 规划页 `/inventory/planning/:skuId`：打开谁就显示谁。

## 5. 接口与界面

查询参数名统一为 `productScope`。

- 省略或非法值：按 `goods`。
- `accessory`：只返回配件。
- 导出文件名在日期后加 `-goods` 或 `-accessory`。
- 汇总（库存件数、可售、销量、周转、看板 SKU 计数、预警条数）与当次列表同一范围。

界面在现有筛选条放两段开关：「不含配件」「只看配件」。默认第一段。切换后刷新列表与汇总，并把 `productScope` 写入地址栏。开关旁始终有一句短说明，见 §6。

商品主数据在配件行显示「配件」标记，便于核对编码是否被判对。主数据默认列表不套 `productScope`。

## 6. 说明文案

不含配件是默认口径，说明跟操作放在一起，不收进帮助中心才算完成。面向用户的句子不写函数名。识别方式「编码变化段含 P，或主数据标记为配件」只在需求计划和预测说明里各出现一次；可切换页面的短说明不重复编码规则。

### 6.1 共用短说明（可切换的页面）

库存总览、库存查询、库存池、未分配供应、经营看板、安全库存、库存预警、补货建议、销量历史、销量分析、预测结果、SKU 规划入口、数据问题队列：开关右侧或下方固定一行。

> 配件不参与销量、预测与备货，默认已排除。需要核对配件时，切换到「只看配件」。

数据问题队列在这句后面接「另有 N 条配件问题」。

经营看板原「主数据全量」改为「不含配件」。

### 6.2 需求计划（不能切换）

列表页流程卡和版本明细页顶栏各放同一段，生成草稿按钮旁再重复一句短的，避免只在折叠说明里出现。

> 本页一律不含配件。配件（编码变化段含 P，或主数据标记为配件）不参与备货，需求计划不生成、不展示配件 SKU。要看配件库存或销量，请到库存查询或销量历史，切换到「只看配件」。

生成区短句：

> 生成时自动跳过配件 SKU，草稿里不会出现配件。

替换现在只写「变化含 P、自动跳过」的旧句。变化段含 P 只出现在上面这段括号里，不再单独当原因。

### 6.3 预测

生成预测卡片（`/data/forecast`）复选框下，默认勾选时：

> 默认不含配件。配件（编码变化段含 P，或主数据标记为配件）销量不作为备货依据，本次预测不会写入配件 SKU。取消勾选后，仅这一版会包含配件，结果页可用「只看配件」查看。

取消勾选时，同一位置改为：

> 本次预测会包含配件 SKU。需求计划仍然不含配件，补货不会按这些配件行下单。

预测结果页（`/data/forecast/:versionId`）除 §6.1 短说明外：

- 当前版本是「不含配件」算出的，用户切到「只看配件」且结果为空时，空状态写：本版预测生成时已排除配件，所以这里没有配件行。若要单独看配件预测，请重新生成并取消「不含配件」。
- 当前版本包含配件时，空状态只用通用的「没有符合筛选的 SKU」，不再说已排除。

预测策略页的方法说明里加一条：默认生成不含配件；需求计划始终不含配件。与 `apps/web/src/lib/forecast-methodology.ts`、需求计划跳过原因 `accessory` 的展示文案对齐，跳过原因改为「配件 SKU 不参与备货预测」。

### 6.4 不要求长说明的地方

商品主数据、单 SKU 规划页、采购跟单、FOB、成本核算只保留行上的「配件」标记，不放备货口径长文。成本单里的五金配件与这里的配件 SKU 不是同一件事，成本页不引用本节文案。

## 7. 实现要点

- 只扩展 `apps/web/server/lib/planning-accessory-filter.ts`，供上述读接口复用。内存过滤处继续用 `isAccessorySku`，与 SQL 条件保持同一判定。
- 各列表 service 增加可选 `productScope`，路由缺省填 `goods`。
- 经营看板的 SKU 计数、健康度计数默认不含配件，文案改为当前口径，不再写「主数据全量」。
- 预测对话框把「不含配件」传到计算入参；勾选时沿用现有跳过，取消勾选时不再滤掉配件 SKU。勾选状态变化时，说明文案按 §6.3 切换。
- 需求计划列表、版本明细、预测生成、预测结果，以及 §4.1 各页，都渲染 §6 的说明；说明是页面正文，不是仅 title 提示。

## 8. 验收

- 打开库存查询、库存总览、销量历史：默认看不到 `DJ478585_2P02` 这类配件；切到「只看配件」后只剩配件，汇总随之变化。
- 同一筛选下导出 CSV 与屏幕行一致，文件名带对应后缀。
- 预测默认勾选「不含配件」时，新版本结果里没有配件，生成卡片上能读到「默认不含配件」的说明；取消勾选后说明改为「本次会包含配件」，「只看配件」能看到配件行。勾选「不含配件」生成的版本，结果页切到「只看配件」时，空状态说明本版已排除配件。
- 需求计划列表与版本明细都能读到「一律不含配件、不参与备货」的说明，生成结果仍无配件，且没有范围开关。
- 库存查询等可切换页面，开关旁能读到「默认已排除」的短说明。
- 按 SKU id 打开配件的规划页仍能看到该 SKU，并带「配件」标记。
- 数据问题在默认视图隐藏配件问题，同时能看到配件问题条数。
