# 销售区域 / 履约区域（预测 · 补货 · 健康 · PMC）

日期：2026-11-12  
状态：已确认待实现  
方案：独立 `sales_region` / `fulfillment_region` + 显式映射（方案 2）

## 1. 背景与目标

预测与备货需要增加国家区域维度。现网销量有原文 `station`、库存有物理仓，但没有统一的美/加/欧/英区域口径；预测基线固定 `station=ALL`，补货用「全站预测 × 仓销售占比」拆仓。

目标：

- 销售侧按**销售区域**出需求与预测
- 履约侧按**履约区域**出库存、补货、健康与 PMC 落仓
- 一期区域 1:1，暂不做美加共仓等跨区供货
- 全部站点/仓库显式映射；不自动猜区

## 2. 需求基线（已锁定）

### 2.1 维度

| 项 | 结论 |
|----|------|
| 概念 | 销售区域与履约区域分开；一期码值 1:1 |
| 区域集合 | `US` / `CA` / `EU` / `UK` / `MX` / `BR` / `OTHER` + `UNMAPPED`（映射种子见业务 CSV） |
| OTHER | 仅显式映射进入 |
| UNMAPPED | 预测/补货解析未映射时落入；销量行上可空（展示 `-`） |
| 猜区 | 禁止按站点文案猜区；飞书「区域」汉字仅按受控词表归一（美国→US 等） |
| 跨区供货 | 一期不做（美加共仓后置） |
| 销量区域来源 | **优先**飞书/导入行上区域；为空则 **站点→区域映射**；仍空则不写 |
| 销量仓库来源 | 飞书「仓库」同步写入；导入无仓则空。销量侧基础映射只需站点→区域 |

### 2.2 预测

- 双轴：全/分渠道 × 全/分区域，支持组合查看
- **唯一预测叶子**：分区域 × 分渠道（SKU × 销售区域 × platform × 月）
- 其余三种组合由叶子**加总**，不另训、不另存一套预测
- 原文站点只做归区，不出站点级预测

### 2.3 补货与库存

- 补货按**履约区域**出数；区内可池化后再拆物理仓
- 补货粒度：**履约区域 × 渠道**
- 区域库存共有；按渠道占比分摊后再算缺口
- 占比：**发布预测渠道占比优先**，否则回退该区域历史销量占比

### 2.4 一期范围

| 必含 | 紧随（同口径，不挡首发） |
|------|--------------------------|
| 映射配置、预测、补货、健康/预警、PMC 落仓 | 需求计划（周）、存销分析 |

## 3. 总体架构

```text
飞书日销(站点, 区域汉字?, 仓库?) 
  -> 区域 = 行上区域归一 ?? 站点映射 ?? 空
  -> 仓库 = 行上仓库（可空）
  -> sales_history.sales_region / warehouse_code

销量(station, sales_region?, platform) --行上区域优先否则映射--> 销售区域
                \-> 预测叶子: 区域 × 渠道
                \-> 加总视图: 全区域/全渠道组合

仓库(warehouse_code) --映射--> 履约区域
库存(按仓) --归区--> 区域库存池
                \-> 按渠道占比分摊(预测优先, 否则历史)
                \-> 补货/健康: 履约区域 × 渠道
                \-> PMC 落仓: 履约区域 (+ 可选物理仓)
```

主数据原文不改写：销量保留 `station`，仓保留 `warehouse_code`；区域只经映射得到。

配置层：

1. 站点 → 销售区域  
2. 仓库 → 履约区域  
3. 一期不做「销售区域 → 履约区域」跨区关系表  

## 4. 映射配置

### 4.1 配置对象

| 配置 | 键 | 值 |
|------|----|----|
| 站点映射 | 销量原文 `station`（归一后） | `sales_region` ∈ {US,CA,EU,UK,OTHER} |
| 仓库映射 | `warehouse_code` | `fulfillment_region` ∈ 同上 |

`UNMAPPED` **不得**作为映射目标写入配置。

### 4.2 运行时解析

1. 命中映射 → 配置区域  
2. 未命中 → `UNMAPPED`  
3. 禁止启发式猜区  
4. 映射变更不影响已发布预测版本行；仅影响后续生成/任务  

### 4.3 OTHER vs UNMAPPED

| | OTHER | UNMAPPED |
|--|-------|----------|
| 进入方式 | 显式配置 | 无配置自动落入 |
| 计算 | 正式参与 | 正式参与（带数据质量含义） |
| 运营 | 确认归「其他」 | 补映射到正确区域或 OTHER |

### 4.4 数据质量（不阻断）

- 统计未映射站点销量占比、未映射仓库存占比  
- 进入数据问题队列或等价告警（如 `unmapped_station` / `unmapped_warehouse`）  
- 预测/补货/PMC 照常；产出带 `UNMAPPED` 标签  

### 4.5 维护

- 列表、搜索、CSV 导入导出  
- 校验：区域枚举合法；目标不能为 `UNMAPPED`  
- `warehouses.region_group` / `country_code` 仅可作初始化参考或对账；**权威以映射表为准**  
- 权限：系统配置类（实现时对齐 RBAC，例如 `data.region_mapping`）

## 5. 预测设计

### 5.1 叶子与组合

| 视图 | 来源 |
|------|------|
| 分区域 × 分渠道 | 读叶子 |
| 分区域 × 全渠道 | 同区域各渠道加总 |
| 全区域 × 分渠道 | 同渠道各区域加总 |
| 全区域 × 全渠道 | 全部叶子加总 |

加总对生效日均（手工优先于系统）按量求和；非加总字段在合并行置空或标 `mixed`。

### 5.2 相对现网

| 现网 | 本期 |
|------|------|
| `station=ALL` × platform | 销售区域 × platform |
| 全站靠 ALL | 全区域 = 各区域叶子之和 |
| 站点不进粒度 | 站点仅归区 |

行上使用独立区域字段（如 `sales_region`），**不用**销量原文意义上的 `station` 表示区域，避免语义混淆。

### 5.3 版本、护栏、准确率

- 一次基线为出现的每个区域×渠道生成叶子（含 OTHER / UNMAPPED）  
- 护栏默认可按项目组 × 销售区域 × 月；分平台护栏与现网兼容  
- 实际销量经站点映射后与区域×渠道预测对齐  
- 历史 `station=ALL` 版本只读保留，标注迁移前口径；不自动拆成区域行  

## 6. 补货 · 健康 · PMC

### 6.1 决策粒度

- 最小单元：履约区域 × 渠道（一期码 = 销售区域）  
- 区内多仓：区域供给池 → 再按现有仓占比/仓网规则拆物理仓  
- 美区互调延后等逻辑仅在同一履约区域内生效  
- UNMAPPED / OTHER 同等出建议  

### 6.2 需求

- 主路径：发布版叶子 销售区域 × 渠道  
- 无该叶子时：建议回退**同区域同渠道**历史日均，不回退全站  

### 6.3 渠道库存分摊（计划分摊，不落渠道台账）

1. 汇总履约区域下已映射仓的有效供给  
2. 渠道库存 = 区域库存 × 渠道占比  
3. 占比：发布预测渠道占比 → 否则近窗历史（建议默认 90 天可配）  
4. 向下取整 + 最大余数，件数守恒  

### 6.4 补货建议字段

- 必带：`fulfillment_region`、`platform`  
- 可选：区内拆分后的 `warehouse_code`  
- UNMAPPED 可采纳进 PMC，目标标未映射，靠人工后续处理  

### 6.5 健康 / 预警

- 按履约区域 × 渠道出灯与预警  
- 列表支持区域、渠道、未映射筛选与未映射占比提示  

### 6.6 PMC 落仓

- 计划行写履约区域；有拆仓则写物理仓，否则区域已定、仓可待定  
- UNMAPPED：警告但不硬阻断确认  
- 发运/三池仍以物理仓为准  

### 6.7 替换旧拆仓路径

- 旧：全站预测 × 周转区域销售占比 → 物理仓需求  
- 新：区域×渠道预测 → 区域需求；库存按渠道分摊；区内再拆仓  
- 旧占比可作区内二次分配参考，不再承担跨销售国家职责  

## 7. 页面与权限

| 能力 | 要点 |
|------|------|
| 映射配置 | 双表维护、CSV、未映射量级、禁止目标 UNMAPPED |
| 销售预测 | 区域/渠道筛选；四种组合视图 |
| 补货 / 健康 | 履约区域、渠道、未映射筛选 |
| PMC | 展示履约区域与目的仓；未映射警告 |

预测/补货/预警/PMC 沿用现有模块权限，仅扩展筛选项。

## 8. 迁移

1. 上线映射表 → 未配置前全部解析为 UNMAPPED  
2. 运营导入首版映射  
3. 新预测版本按区域×渠道生成；旧 ALL 只读  
4. 补货/健康/PMC 切换新口径  
5. 以未映射占比为流程门禁（非系统硬阻断），优先清高销站点与主仓  

## 9. 非目标（一期）

- 美加共仓 / 跨区履约关系表  
- 原文站点级预测  
- 未映射硬阻断任务  
- 独立存储「全区域/全渠道」预测行  
- 渠道库存正式台账  
- 需求计划、存销分析的完整改造（紧随，同口径）  

## 10. 验收标准

- [ ] 站点/仓：有映射用映射，无映射为 UNMAPPED，无自动猜区  
- [ ] OTHER 仅能显式配置进入  
- [ ] 预测只写区域×渠道叶子；四种组合加总与叶子合计一致  
- [ ] 补货/健康按履约区域×渠道；库存分摊预测优先否则历史，件数守恒  
- [ ] 未映射不阻断，可建议、可进 PMC，带未映射标识  
- [ ] PMC 行带履约区域；有拆仓则带物理仓  
- [ ] 旧全站版本可查，不参与新补货主路径  
- [ ] 未映射站点/仓可在数据问题或告警中看见  

## 11. 风险

- 映射未备齐时 UNMAPPED 量大，决策噪声高 → 上线用映射完备度作流程门禁  
- 渠道分摊是计划假设；FBA 等专属库存混算会偏 → 二期可加渠道专属库存例外  
- 加区若无真实履约仓映射，建议可能落空池或 UNMAPPED  

## 12. 后续（非一期）

- 销售区域 → 履约区域跨区供货（如 CA 需求由 US 履约）  
- 需求计划周、存销分析全面切区域口径  
- 渠道专属库存例外  
- EU 内高销国家拆独立区域（若业务需要）
